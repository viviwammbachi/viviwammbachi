## My working approach

1. Clarify the decision question and required deliverables.
2. Review data quality, coordinate systems, and limitations.
3. Complete a documented and reproducible analysis.
4. Deliver clear maps, organized files, and a concise explanation of the results.
5. State uncertainty honestly and avoid presenting screening indicators as confirmed facts.
